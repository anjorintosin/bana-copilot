About

Bana Copilot is an overlay that sits on your screen during interviews. It listens when you ask it to, reads what’s on screen when you send it, and drafts what to say — it does not auto-answer.

Desktop 0.1.2

What you can do

  • Ask anything — type in the bar and press Enter. That’s normal chat: greetings, follow-ups, or a question you heard.
  • Assist — the arrow next to the bar packs recent audio (and screen when you didn’t type) so it can draft an answer for the live interview.
  • Start session — begins a timed session. Click again to end it and open History on that session.
  • Mode — switch how Assist should answer, and attach resumes or notes. General is built in; create others for coding, behavioral, and so on.
  • Visibility — keep the HUD off Zoom / Meet screen share. Turn that off in General if you want it visible.
  • Solve what’s on screen — the screen icon captures the display and works the problem you can see (coding, prompts, docs).
  • Settings — key, modes, shortcuts, and look.
  • History — reopen past sessions without leaving the HUD.

How to use it

  1. Add your own model key on General (or during first-run setup). Assist cannot answer without it.
  2. Optional: open Modes, attach a resume or job notes, and press Use on the mode you want.
  3. Start a session from the HUD. Live shortcuts only work during a session.
  4. When they ask, type it, press Assist, or tap Screen if the question is on the display.
  5. Read the reply in the HUD. Copy with the icon under the bubble. Scroll down for the rest of a long answer.
  6. The B mark collapses the HUD back to the short bar. Shortcuts are on the Shortcuts page if you want keys instead of clicks.
