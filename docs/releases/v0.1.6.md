## Install
Verify the checksum of your downloaded file against the release assets before installing.

**Mac:** macOS 12 or newer. Apple Silicon (M1–M4): the `arm64` DMG. Intel Macs: the `x64` DMG.
If macOS Gatekeeper flags an unnotarized test build, verify the package integrity, then open it via **System Settings → Privacy & Security → Open Anyway** (or remove the quarantine attribute in Terminal with `xattr -cr "/Applications/Bana Copilot.app"`).

**Windows:** `Bana.Copilot-Setup-0.1.6.exe`.
Verify the publisher in file properties before going past the SmartScreen prompt (*More info* → *Run anyway*).

**Linux:** most laptops use `x86_64` / `amd64` / `x64`. ARM laptops use `arm64`.
- AppImage: `chmod +x Bana.Copilot-0.1.6-x86_64.AppImage` then run it.
- Ubuntu/Debian: `sudo apt install ./Bana.Copilot-0.1.6-amd64.deb`
- Tarball: unpack `Bana.Copilot-0.1.6-*.tar.gz` and run `bana-copilot`.

## How to start
1. Launch Bana Copilot. Each new version opens onboarding once so you can recheck Microphone, Screen Recording, and Meeting Audio.
2. Press **Continue**. The HUD appears on your screen.

## Already live for 0.1.5
These server fixes are already active, even before you update:
- **Answers the question just asked:** Assist waits for the last words to finish transcribing, so it no longer answers the previous question.
- **Uses the whole conversation:** every answer sees the full transcript of the session and your earlier answers, so follow-ups like "why that one?" build on what was already said.
- **Speech before the screen:** Assist answers what was said or typed first, and only solves the screen when nothing new was said.
- **Modes work right away:** a new mode, a file added to it, or switching modes takes effect on the next answer, without restarting. Files are read in full.

## What's new in 0.1.6
- **Ask while an answer is writing:** a new question replaces the answer in progress instead of "Still working". The replaced answer is marked "Stopped: you asked something new."
- **Typed questions are kept:** if a question can't be sent, it stays in the box so Enter retries it.
- **Accurate "Viewed screen":** the label only appears on answers that came from your screen.
- **Answers with screenshots display reliably:** fixes a display error when an answer started with a screenshot attached.
- **See your saved knowledge:** Home → Modes → General now lists your resume, role, and stories, and every saved file has a **View** button to read it in full.
- **Encrypted connection:** the app connects to the server over HTTPS.
- **Clearer onboarding:** the Assist shortcut step is marked optional.
