## Install
**Mac:** macOS 12 or newer. Apple Silicon (M1–M4): the `arm64` DMG. Intel Macs: the `x64` DMG. If macOS says the app is damaged, it is Gatekeeper on a download Apple has not checked yet. In Terminal:

xattr -cr "/Applications/Bana Copilot.app"

**Windows:** Bana.Copilot-Setup-0.1.4.exe. If SmartScreen warns, More info → Run anyway.

**Linux:** most laptops use `x86_64` / `amd64` / `x64`. ARM laptops use `arm64`.
- AppImage: `chmod +x Bana.Copilot-0.1.4-x86_64.AppImage` then run it. Works on Ubuntu 24.04 without extra installs.
- Ubuntu/Debian: `sudo apt install ./Bana.Copilot-0.1.4-amd64.deb`
- Anything else: the `.tar.gz`, then run `bana-copilot` inside it.

## How to start
1. Open the app. Each new version starts at onboarding once: your key is already saved, so press Continue, and confirm the permissions.
2. Pick a mode (interview type) and add its documents if you have them.
3. Start a session. When they ask something, press **Assist**, or type your question and press Enter.

Testers add their own model key. No shared server key.
