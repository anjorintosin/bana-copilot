## Install
**Mac:** macOS 12 or newer. Apple Silicon (M1–M4): the `arm64` DMG. Intel Macs: the `x64` DMG. If macOS says the app is unverified or damaged, remove quarantine in Terminal:

```bash
xattr -cr "/Applications/Bana Copilot.app"
```

**Windows:** `Bana.Copilot-Setup-0.1.5.exe`. If SmartScreen warns, click *More info* → *Run anyway*.

**Linux:** most laptops use `x86_64` / `amd64` / `x64`. ARM laptops use `arm64`.
- AppImage: `chmod +x Bana.Copilot-0.1.5-x86_64.AppImage` then run it.
- Ubuntu/Debian: `sudo apt install ./Bana.Copilot-0.1.5-amd64.deb`
- Tarball: unpack `Bana.Copilot-0.1.5-*.tar.gz` and run `bana-copilot`.

## How to start
1. Launch Bana Copilot. Onboarding opens automatically on first run to check your Microphone, Screen Recording, and Meeting Audio permissions.
2. Click **Check** on each permission to verify access.
3. Once completed, the compact HUD pill appears on your screen.

## What's new in v0.1.5
- **Wide top typing space:** The input field is now positioned permanently at the top across both collapsed and expanded states.
- **Top Assist button:** In expanded mode, the Assist button sits at the top right, drafting answers with live context and screen capture.
- **Stealth Detectability indicator:** A slashed eye icon indicates the HUD is undetectable/hidden from screen share (Zoom, Meet, Teams). When visible, it alerts with an orange highlight.
- **HUD movement shortcuts:** Nudge the overlay position anywhere on your screen using default shortcuts `⌘↑`, `⌘↓`, `⌘←`, and `⌘→`.
- **Streamlined permissions:** Onboarding now jumps straight into permissions with on-demand checks and visual green checkmark indicators.
- **Centralized Model Integration:** Server-side managed OpenAI processing so client testers no longer need to configure personal API keys.
