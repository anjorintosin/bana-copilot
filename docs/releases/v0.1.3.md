## Install
**Mac:** macOS 12 or newer. Apple Silicon (M1–M4): the `arm64` DMG. Intel Macs: the `x64` DMG. If macOS says the app is damaged, it is Gatekeeper on an unsigned download. In Terminal:

xattr -cr "/Applications/Bana Copilot.app"

**Windows:** Bana.Copilot-Setup-0.1.3.exe. If SmartScreen warns, More info → Run anyway.

**Linux:** most laptops use `x86_64` / `amd64` / `x64`. ARM laptops use `arm64`.
- AppImage: `chmod +x Bana.Copilot-0.1.3-x86_64.AppImage` then run it. Works on Ubuntu 24.04 without extra installs.
- Ubuntu/Debian: `sudo apt install ./Bana.Copilot-0.1.3-amd64.deb`
- Anything else: the `.tar.gz`, then run `bana-copilot` inside it.

## How to start
1. Open the app. Onboarding asks for your model key, your resume or notes, and every permission the app needs, once.
2. Pick a mode (interview type) and add its documents if you have them.
3. Start a session. When they ask something, press **Assist**. It answers what was just asked, using what was said and your screen.

Testers add their own model key. No shared server key.

## This build (0.1.3)
- **Follow-ups:** Assist answers the newest question, including follow-ups like "go deeper on that", "why?", or "give me an example", instead of repeating the last answer.
- **Your question stays on top:** the question you asked shows first; earlier questions and answers are above when you scroll up.
- **Answers read naturally:** sentences by default; numbered steps only when the answer really is steps.
- **Answer check:** a warning appears under an answer that may contradict your resume, your mode, or what you already said.
- **Modes:** each mode keeps its own instructions and documents.
- **Cleaner loading:** just the dots while an answer starts.
- **Permissions once:** all collected at onboarding.
- **Linux:** ARM builds, Ubuntu 24.04 AppImage fix, Wayland support (the system asks once per session which screen to share). Listen uses your microphone on Linux.
- **Mac:** Intel and Apple Silicon builds, macOS 12+. On macOS older than 13.2, Listen uses your microphone.
